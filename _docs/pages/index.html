Cascade docs

Cascade is an animation library for Unity UI Toolkit. It animates any VisualElement at runtime with one line of C#: fades, moves, scales, colors, sizes, springs, staggered lists and screen transitions.

It works with UXML/USS and UI Toolkit (UIElements) in Unity 6000.0 and later. It has no third-party dependencies and allocates nothing per frame. It doesn't support uGUI (Canvas).

using Cascade;

panel.Animate()
     .Fade(1f, 0.3f).From(0f).Ease(Ease.OutCubic)
     .MoveY(0f, 0.3f).From(24f).Ease(Ease.OutCubic);   // both run together

Lite and Pro

Cascade comes in two tiers. Lite is free and MIT licensed, and covers the tween engine. Pro is a superset: it includes everything in Lite and adds the parts that are hard to write yourself.
