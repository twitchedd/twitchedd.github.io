Changelog

What changed in each release, newest first. Lite and Pro share one version number and ship together. Items marked Pro are only in Pro; everything else is in both.

To update, open Package Manager, select Cascade under My Assets and click Update. The full changelog also ships inside the package as CHANGELOG.md.

1.2.1 (2026-11-14)

Changed

  • Clearer guidance for AI coding assistants. The AI guide and the rules written by Tools > Cascade > Set Up AI Assistants Pro now explain three things that misled assistants: Loop() repeats only the verb right before it, never a Then() chain; Delay() delays the verb before it, so a Delay before any verb does nothing; and the stagger example used an AnimateEach overload that doesn't exist.
  • A shorter, code-first AI guide. AI-GUIDE.md is a little over half its old size and has a new "Behaviour and exact names" section: which animations replace a running one, when From() applies, OnComplete vs OnSettled, counting a number with Value(), and the exact ease and verb names. The JSON sequence format moved to its own file, AI-GUIDE-JSON.md. Assistants get Cascade code right first time more often and spend fewer tokens doing it.
  • The Loop() documentation comment (what your IDE shows) now says it loops only the most recent verb.

After upgrading, run Set Up AI Assistants again to refresh the rules in your project.

1.2.0 (2026-11-11)

Added

  • Juice verbs. Shake(strength, duration) and Punch(offset, duration) in both tiers; in Pro also a tunable Shake (vibrato, decay, axis), PunchScale, PunchRotate, Pulse, Wiggle and Pop. They start and end at rest, layer on top of a running move or scale instead of cancelling it, and put the element back if cancelled. Under reduced motion they skip straight to rest.
  • At(seconds): place the verbs that follow at a time from the start of the sequence while the Then() chain carries on, all under one handle.
  • Style verbs: BorderRadius, BorderWidth, BorderColor, FontSize, Padding, Tint, Right and Bottom, with matching MotionChannel values for StopAnimations(channel).
  • WithVelocity(unitsPerSecond) Pro: start a spring already moving, so a thrown card keeps the speed of the drag as it springs home.
  • Code checks: an analyzer in the Unity console and your IDE that warns about animation code that compiles but doesn't do what was meant (CASC001 to CASC008), such as a duration in milliseconds or an entrance with no start value.
  • Tools > Cascade > Set Up AI Assistants Pro: writes Cascade's rules into AGENTS.md, CLAUDE.md, Copilot and Cursor files, keeping their existing content.
  • A "juice & timing" section in the gallery sample, and keyboard navigation for the gallery's section rail.

Changed

  • Pro Three showcase samples redesigned: the Starfall Combat HUD, the Pocket Shop (now The Gilded Anvil, a medieval shop) and Mission Control (now a SaaS dashboard with a command palette).

Fixed

  • The JSON schema and the inspector treated Nudge as a from/to verb; it takes an x/y offset.
  • A Lite gallery example faded in without .From(0f), so copied on its own it did nothing.

1.1.0 (2026-10-14)

Added

  • Pro Four showcase samples: Mission Control Dashboard, Starfall Combat HUD, Pocket Shop and Afterhours Audio Studio, each a complete animated UI Toolkit screen.
  • Links to these online docs from Package Manager, the README and the getting-started guide.

Fixed

  • The documentation files and sample READMEs could be missing from the Asset Store download.
  • Lite: assembly references to Cascade.Lite.Runtime broke on every update.
  • Lite: the AI guide's fade-in examples omitted .From(0f), so they did nothing on a visible element.

1.0.1 (2026-10-02)

Fixed

  • A compile error (CS0619) in the UI Animator inspector on newer Unity 6 editors.

1.0.0 (2026-08-25)

First public release: the tween engine with fades, moves, scales, rotation, colors and sizes, the full easing set, sequencing, loops, await, Value() for plain numbers, OnSettled and reduced motion. Pro adds springs, stagger, enter/exit and screen transitions, hover/press/focus animations, named states, the no-code UI Animator, JSON sequences and shadow/glow.
