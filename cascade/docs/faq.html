    FAQ

    Which Unity versions does Cascade support?

    Unity 6000.0 and later. Each release is tested on the oldest supported version and on a current one. Animated blur and tint need Unity 6.3 or later; on older versions those two verbs do nothing.

    Does it work with uGUI (Canvas)?

    No. Cascade animates UI Toolkit VisualElements only (UXML/USS, also called UIElements).

    Does it work in the editor UI or only at runtime?

    It's built for runtime UI: game menus, HUDs and app screens rendered by a UIDocument. The UI Animator component (Pro) also previews in edit mode.

    What's the difference between Lite and Pro?

    Lite is the free tween engine: every verb, easing, sequencing, loops, await and reduced motion. Pro adds springs, stagger, enter/exit and screen transitions, hover/press/focus, named states, the no-code UI Animator, JSON sequences, and shadow/glow. See the table on the overview.

    How do I upgrade from Lite to Pro?

    Remove Cascade Lite, then install Cascade Pro. Pro contains everything in Lite with the same namespace and calls, so your code keeps compiling. Don't install both at once.

    What's the license?

    Cascade Lite is MIT licensed. Cascade Pro uses the standard Unity Asset Store license.

    Which platforms?

    All platforms UI Toolkit supports. Cascade is pure C# with no native code and no dependencies.

    Why not just use USS transitions?

    Use them for hover colors and simple toggles. They can't run steps in order, stagger a list, await the end, or spring. How to animate a VisualElement compares the options.

    Does it allocate every frame?

    No. Tweens are pooled and the update loop is allocation-free; the test suite measures it. See Performance and lifecycle.

    Does it keep animating when the game is paused?

    Yes. Cascade runs on unscaled time, so a pause menu animates with Time.timeScale = 0.

    My fade-in does nothing. Why?

    The element is already at full opacity, so it fades from 1 to 1. Add .From(0f). More in Common mistakes.

    Can an AI assistant write Cascade code?

    Yes. Install the agent skill with npx skills add twitchedd/cascade-skill. See AI assistants and the skill.

    Where do I get help or report a bug?

    Use the contact options on the twitched site or the publisher page on the Unity Asset Store. Include your Unity version, the tier, and the smallest code that shows the problem.
